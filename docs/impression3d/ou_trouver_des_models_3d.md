# Où trouver des modèles 3D ?

Le moyen le plus facile pour débuter dans l'impression 3D consiste à trouver des objets 3D sur internet **gratuitement**. Les fichiers se présentent habituellement au format `[STL]` `[OBJ]` `[3MF]` ou `[STEP]`.


## Incontournables : Grandes plateformes généralistes


---

### <a href="https://www.printables.com/" target="_blank" rel="noopener noreferrer">Printables</a>

**Plateforme** : Prusa  
**Formats** : `[STL]` `[3MF]` avec profils PrusaSlicer  
**Inscription** : Sans  

- **Avantage** : Meilleure qualité de documentation
- Idéal pour : Débutants, projets pédagogiques
- Fichiers prêts à imprimer, souvent multi-compatibles
- Documentation technique complète (support, orientation, réglages)
- Concours réguliers, très utile pour projets pédagogiques


---

### <a href="https://www.makerworld.com/" target="_blank" rel="noopener noreferrer">Makerworld</a>

**Plateforme** : Bambu Lab  
**Formats** : Tous formats, optimisés pour imprimantes Bambu  
**Inscription** : Requise  

- Très grosse communauté
- Fichiers pré-paramétrés pour machines Bambu
- **Makerlab** : génération de modèles 3D à partir de photos, descriptions textuelles ou paramètres prédéfinis
- Idéal pour : Utilisateurs Bambu Lab

---

### <a href="https://www.printables.com/" target="_blank" rel="noopener noreferrer">Printables</a>

**Plateforme** : Ultimaker  
**Formats** : `[STL]`  
**Inscription** : Sans 


- **Avantage** : Meilleure qualité de documentation
- Idéal pour : Débutants, projets pédagogiques
- Fichiers prêts à imprimer, souvent multi-compatibles
- Concours réguliers, très utile pour projets pédagogiques


---

### <a href="https://www.thingiverse.com/" target="_blank" rel="noopener noreferrer">Thingiverse</a>

**Plateforme** : MakerBot (plus ancienne bibliothèque communautaire)  
**Formats** : `[STL]` dominant, parfois sources `[STEP]` `[F3D]` `[SCAD]`  

- **Customizer** : application OpenSCAD paramétrique intégrée
  - Générer des variantes sans logiciel de CAO
  - Excellent pour initier les élèves à la modélisation paramétrique
- Aucune vérification qualité : nécessite de filtrer avant impression
- Base de données massive et ancienne
- **Avantage** : Apprentissage et modélisation paramétrée
- Idéal pour : Personnalisation, pédagogie, modélisation

---

## Outils de recherche et métamoteurs

### <a href="https://www.yeggi.com/" target="_blank" rel="noopener noreferrer">Yeggi</a>

**Type** : Métamoteur de recherche  

- N'héberge aucun fichier, indexe et redirige vers d'autres plateformes
- Indexe : Thingiverse, Cults, MyMiniFactory, etc.
- **Utilité** : Recherche croisée rapide avant de choisir une source fiable
- Idéal pour : Trouver le meilleur modèle via plusieurs sources

---

## Alternatives spécialisées

### <a href="https://www.myminifactory.com/fr" target="_blank" rel="noopener noreferrer">MyMiniFactory</a>

**Label** : "Guaranteed to print"  
**Formats** : Tous formats  

- Chaque modèle testé avant publication → réduit l'échec en atelier
- Filtrage par machine/filament
- Bibliothèque orientée figurines et jeux de plateau
- **Avantage** : Qualité garantie
- Idéal pour : Projets sans risque d'échec

---

### <a href="https://cults3d.com/fr" target="_blank" rel="noopener noreferrer">Cults</a>

**Plateforme** : Française  
**Formats** : `[STL]` `[STEP]` gratuits et payants  

- Licences explicitement indiquées (usage personnel vs commercial)
- Essentiel pour cadres pédagogiques/institutionnels
- Interface en français
- **Avantage** : Clarté juridique et support français
- Idéal pour : Établissements, usage institutionnel

---

### <a href="https://www.youmagine.com/" target="_blank" rel="noopener noreferrer">YouMagine</a>

**Écosystème** : Ultimaker/Cura  
**Philosophie** : Open source  

- Licences copyleft favorisées
- Cohérent avec logique de partage libre en fablab
- Idéal pour : Projets open source, fablabs

---

### <a href="https://pinshape.com/" target="_blank" rel="noopener noreferrer">Pinshape</a>

**Type** : Marketplace mixte (gratuit/payant)  
**Orientation** : Design produit et objets fonctionnels du quotidien

---

### <a href="https://sketchfab.com/" target="_blank" rel="noopener noreferrer">Sketchfab</a>

**Type** : Visualiseur WebGL interactif  

- **Non dédié** à l'impression 3D
- Utile pour scans 3D et photogrammétrie
- Téléchargement et impression selon licence du modèle
- À vérifier au cas par cas
- Idéal pour : Scans 3D, actifs VFX

---

## Ressources avancées / Professionnelles

### <a href="https://3dexport.com/" target="_blank" rel="noopener noreferrer">3DExport</a>

**Orientation** : Rendu 3D, jeu vidéo  
**Formats** : `[OBJ]` `[FBX]` + section `[STL]` imprimable  

- Moins adapté aux débutants
- Plus proche d'un usage professionnel/CAO
- Idéal pour : Professionnels, VFX

---

### <a href="https://www.cgtrader.com/" target="_blank" rel="noopener noreferrer">CGTrader</a>

**Type** : Marketplace professionnelle VFX/jeu vidéo  
**Tarif** : Majoritairement payante  

- Section imprimable disponible
- Exigences de topologie/maillage plus techniques
- Plus élevé en complexité que les sites grand public
- Idéal pour : Professionnels, projets techniques
